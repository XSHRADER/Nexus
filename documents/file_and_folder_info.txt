PROJECT FILES AND FOLDERS INFORMATION
===================================

PROJECT ROOT:
- Nexus/
  Main project folder containing the RAG application source files, documents, environment, and runtime data.

MAIN FOLDERS:

1. Nexus/documents/
   - Stores source documents used for ingestion and retrieval.
   - Contains project-related knowledge files such as nexus_project_info.md.

2. Nexus/program_info/
   - Stores text-based information files about the project.
   - Includes:
     - action_log.txt
     - checklist.txt
     - file_and_folder_info.txt
     - local_ai_models.txt
     - requirements.txt

3. Nexus/vector_store/
   - Stores the embedded vector database and metadata used for retrieval.
   - Contains the Chroma database files and hash metadata.

4. Nexus/nexus-env/
   - Virtual environment created for the project.
   - Contains Python packages and scripts used to run the application in isolation.

5. Nexus/__pycache__/
   - Python compiled bytecode cache generated during execution.
   - Usually used for faster import times and can be ignored safely.

MAIN FILES:

1. Nexus/README.md
   - Project overview and instructions.

2. Nexus/ingest.py
   - Script used to load and process documents into the vector store.

3. Nexus/loaders.py
   - Contains helper functions for loading data and preparing it for indexing.

4. Nexus/retrieve.py
   - Script used to query the vector store and retrieve relevant information.

5. Nexus/rag_pipeline.py
   - Main pipeline for retrieval-augmented generation using the AI model and vector database.

6. Nexus/ACTION_LOG.md
   - Markdown version of the project action history.

7. Nexus/.gitignore
   - Lists files and folders ignored by Git.

TEXT INFORMATION FILES:

- Nexus/program_info/action_log.txt
  - Records the actions performed from the beginning of the project.

- Nexus/program_info/checklist.txt
  - Stores task checklist items or setup notes.

- Nexus/program_info/local_ai_models.txt
  - Lists the AI models used by the project.

- Nexus/program_info/requirements.txt
  - Lists the Python packages required for the project.

- Nexus/program_info/file_and_folder_info.txt
  - This file: overview of project structure and purpose of folders/files.

SUMMARY:
The project is organized into a main application folder, a documents directory for knowledge content, a vector store for embeddings, a virtual environment for dependencies, and a program_info folder for all text-based notes and records.
